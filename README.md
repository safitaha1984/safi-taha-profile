# الموقع الشخصي المهني للمهندس صافي طه | Eng. Safi Taha Professional Profile

الموقع الشخصي المهني المتكامل للمهندس صافي طه - مستشار تقني وتنفيذي وخبير الذكاء الاصطناعي والأتمتة الصناعية

## 🚀 المميزات الرئيسية

### 1. **المساعد الذكي المتقدم (AI Chatbot)**
- مدعوم بـ Google Gemini API
- دعم فني واستشارات على مدار الساعة
- ردود ذكية في مجالات:
  - صيانة الأجهزة الذكية واللحام الدقيق
  - الأتمتة الصناعية (PLC/SCADA)
  - ماكينات CNC
  - إنفرترات الطاقة الشمسية
  - الكتب والمؤلفات الهندسية

### 2. **لوحة التحكم السرية**
- دخول بثلاث نقرات على الأيقونة في الهيدر
- أو عبر `Ctrl + Shift + S`
- إدارة كاملة للمحتوى ديناميكياً

### 3. **الأقسام الرئيسية**
- المسيرة المهنية والخبرات
- الخدمات والاستشارات
- الكتب والمؤلفات
- قصص النجاح
- معرض الإنجازات
- البرامج التدريبية المعتمدة
